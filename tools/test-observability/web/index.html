How to update this view

Run the collector on the code you want to demonstrate.

python3 tools/test-observability/dashboard.py run

Freeze a completed run before Devin starts.

python3 tools/test-observability/dashboard.py baseline RUN_ID

After applying Devin’s changes, run the collector again. New runners register in config.json. Results stay local and can be exported as CI artifacts.
